Chat Completions API

Basic Request (curl):
curl -X POST http://localhost:8001/v1/chat/completions \ -H "Authorization: Bearer sk-sahon-personal-2024" \ -H "Content-Type: application/json" \ -d '{"model":"deepseek-coder-1.3b","messages":[{"role":"user","content":"হ্যালো ভাইয়া"}],"stream":false}'
Streaming Request:
curl -X POST http://localhost:8001/v1/chat/completions \ -H "Authorization: Bearer sk-sahon-personal-2024" \ -H "Content-Type: application/json" \ -d '{"model":"local-code-gen","messages":[{"role":"user","content":"Hello"}],"stream":true}'
Python Request:
python -c "import httpx; r=httpx.post('http://127.0.0.1:8001/v1/chat/completions', headers={'Content-Type': 'application/json', 'X-HelloZombie-Status': 'Setup-Complete'}, json={'model': 'deepseek-coder-1.3b', 'messages': [{'role': 'user', 'content': 'হ্যালো ভাইয়া'}], 'stream': False}); print(r.json())"

Port Management

Check Port Usage (Windows):
Get-NetTCPConnection -LocalPort 8001,8002,8003,8004,8010,8006,8007,8100 -ErrorAction SilentlyContinue | Select-Object LocalPort, State
Kill Process on Port (Windows):
$port = 8001; Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
💡 Change $port variable to target specific port
