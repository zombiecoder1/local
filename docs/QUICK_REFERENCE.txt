🧪 টেস্ট করুন (স্ক্রিপ্ট চলার সময় অন্য terminal এ):

Model Server:
  curl -X POST http://127.0.0.1:8155/api/generate \
    -H "Content-Type: application/json" \
    -d '{"model":"deepseek-coder-1.3b","prompt":"test","stream":false}'

Agent Server:
  curl -X POST http://127.0.0.1:8001/chat \
    -H "Content-Type: application/json" \
    -d '{"message":"test"}'

Proxy Server:
  curl -X POST http://127.0.0.1:5010/v1/chat/completions \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer DUMMY_API_KEY_FOR_LOCAL" \
    -d '{"model":"deepseek-coder-1.3b","messages":[{"role":"user","content":"test"}],"stream":false}'
