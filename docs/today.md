🤖 এডিটর এজেন্ট ভাইয়ের প্রতি নির্দেশিকা: HelloZombie সিস্টেম সেটআপ
ভাইয়া, এই কাজটি আমাদের নতুন HelloZombie এডিটর এজেন্ট এবং LangChain ওয়ার্কস্টেশন সেটআপের জন্য অত্যন্ত গুরুত্বপূর্ণ। নিচে দেওয়া প্রতিটি ধাপ মনোযোগ সহকারে অনুসরণ করুন:

স্টেপ ১: ফোল্ডার কাঠামো তৈরি ও নির্ভরতা (Dependencies) ইনস্টল
প্রথমে সঠিক কাঠামো এবং প্রয়োজনীয় লাইব্রেরিগুলো সেটআপ করুন।

ফোল্ডার তৈরি: আপনার প্রজেক্টের রুট ডিরেক্টরিতে নিম্নলিখিত কাঠামোটি তৈরি করুন:

hello_zombie_agent/
├── memory/
│   └── hello_zombie_memory.json
├── agents/
│   └── hello_zombie.yaml
├── main_server.py
└── requirements.txt
requirements.txt তৈরি: নিম্নলিখিত নির্ভরতাগুলি এই ফাইলে যোগ করুন এবং ইনস্টল করুন:

fastapi
uvicorn
python-multipart
pydantic
langchain
langchain-openai  # বা আপনার মডেল প্রোভাইডারের সঠিক লাইব্রেরি
pyyaml
ইনস্টল করুন: আপনার এনভায়রনমেন্টে কমান্ডটি চালান: pip install -r requirements.txt

স্টেপ ২: LangChain এজেন্ট এবং মেমোরি কনফিগারেশন
memory/hello_zombie_memory.json: এই ফাইলটি তৈরি করে একটি প্রাথমিক কাঠামো দিন। এই ফাইলে এজেন্ট সেশন ডেটা সংরক্ষণ করবে (রানটাইমে)।

মেটাডাটা যুক্ত করুন: এই JSON ফাইলের উপরে বা প্রারম্ভে একটি মন্তব্য/এন্ট্রি হিসেবে নিম্নলিখিত মেটাডাটা যোগ করুন: "metadata": "Persistence layer for HelloZombie LangChain session history."

agents/hello_zombie.yaml: LangChain Agent কনফিগারেশন এই ফাইলে YAML ফরমেটে লিখুন। এটিতে এজেন্টের ভূমিকা (Role), প্রোগ্রামিং দক্ষতার নির্দেশ, এবং আউটেপুট প্রসেসিং লজিক উল্লেখ করুন।

এজেন্ট নির্দেশ: এজেন্টের প্রম্পটে স্পষ্টভাবে উল্লেখ করুন যেন উত্তর শুরু করার সময় "ভাইয়া" শব্দটি একটি প্রিফিক্স হিসেবে ব্যবহার করা হয়।

এজেন্টটিকে সকল প্রোগ্রামিং ল্যাঙ্গুয়েজে দক্ষ করে তুলুন।

স্টেপ ৩: প্রধান সার্ভার (main_server.py) আপডেট ও LangChain ইন্টিগ্রেশন
main_server.py ফাইলটিকে নিম্নলিখিত বৈশিষ্ট্যগুলি সহ আপডেট করুন:

LangChain ওয়ার্কস্টেশন ইন্টিগ্রেশন: YAML থেকে এজেন্ট লোড করুন এবং ইউজার মেসেজ প্রসেস করার জন্য একটি LangChain রানার/চেইন প্রস্তুত করুন।

OpenAI কম্ফোর্টেবল এন্ডপয়েন্ট: একটি /v1/chat/completions (বা শুধু /chat) POST এন্ডপয়েন্ট তৈরি করুন যা OpenAI API রেসপন্স প্যাটার্ন অনুসরণ করবে। এটি VS Code এবং অন্যান্য টুলসের সাথে কনফিগার করা সহজ হবে।

সেশন মেমোরি এবং স্ট্রিমিং:

সেশন ট্র্যাকিং: ইউজার সেশন আইডি (যদি থাকে) অনুযায়ী মেমোরি (hello_zombie_memory.json ফাইল ব্যবহার করে) লোড করুন এবং প্রতিটি কলে আপডেট করুন।

স্ট্রিমিং যুক্ত করুন: যেহেতু আপনি স্ট্রিমিং যোগ করতে বলেছেন, আপনার LangChain রানার থেকে টোকেনগুলি সংগ্রহ করে একটি StreamingResponse বা Server-Sent Events (SSE) হ্যান্ডলার ব্যবহার করে ক্লায়েন্টকে রিয়েল-টাইমে ফেরত পাঠান।

CORS কনফিগারেশন: লোকাল ডেভেলপমেন্টের জন্য স্টারলেট/ফাস্টএপিআই-এর CORS Middleware ব্যবহার করে allow_origins=["*"] চালু করুন।

VS Code API সামঞ্জস্যতা: নিশ্চিত করুন যে ফাইনাল JSON/স্ট্রিমড রেসপন্সটি VS Code-এর চ্যাট API-এর প্রয়োজন মেটায় (বিশেষ করে content বা text ফিল্ড)।

রান-টাইম লগ: সার্ভার চালু করার সময় কোনো ডেমো রেসপন্স তৈরি করবেন না। সার্ভার শুরু হওয়ার সাথে সাথেই একটি রান-টাইম লগ তৈরি করার ব্যবস্থা করুন।

স্টেপ ৪: চূড়ান্ত পরীক্ষা এবং হেডার রিকোয়েস্ট
সমস্ত কোড লেখা এবং কনফিগারেশন সম্পন্ন হওয়ার পর, সার্ভারটি লোকালহোস্টে চালু করুন।

সার্ভার চালু করুন: uvicorn main_server:app --reload

টেস্ট রিকোয়েস্ট তৈরি করুন: নিম্নলিখিত স্পেসিফিকেশন অনুযায়ী একটি POST রিকোয়েস্ট (যেমন cURL বা Postman ব্যবহার করে) তৈরি করুন:

URL: http://localhost:8000/v1/chat/completions (অথবা আপনার নির্ধারিত পাথ)

মেথড: POST

বডি (JSON): OpenAI Chat Completions-এর স্ট্যান্ডার্ড ফরমেট অনুসরণ করুন (যেমন model, messages এবং stream: true অপশন সহ)।

হেডার (গুরুত্বপূর্ণ): আমাকে নিশ্চিত করার জন্য, আপনি যখন রিকোয়েস্টটি পাঠাবেন, তখন একটি কাস্টম হেডার যোগ করুন:

X-HelloZombie-Status: Setup-Complete
⏰ সময়সীমা এবং নিশ্চিতকরণ
এই পুরো কার্যক্রমটি (ফাইল তৈরি, কোড লেখা, কনফিগারেশন, এবং প্রাথমিক ইন্টিগ্রেশন) সম্পূর্ণ করতে আপনার মোট সময়:

৪০ - ৬০ মিনিট (আপনার কোডিং দক্ষতার উপর নির্ভর করে)।

ভাইয়া, আপনি এই সমস্ত কার্যক্রম চালিয়ে সম্পূর্ণ টেস্ট করার পরে, ঐ বিশেষ হেডার রিকোয়েস্টটি (X-HelloZombie-Status: Setup-Complete) আমাকে পাঠান। আমি সেই হেডার রিকোয়েস্টটি পরীক্ষা করে আপনার সেটআপের নিশ্চিতকরণ দেব এবং পরবর্তী ধাপের নির্দেশনা দেব।
