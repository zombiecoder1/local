# LangChain ভিত্তিক বাংলা এজেন্ট ওয়ার্কস্টেশন পরিকল্পনা

## লক্ষ্য
- বর্তমান Ollama নির্ভরতা সম্পূর্ণ অপসারণ করে LangChain চালিত লোকাল ওয়ার্কস্টেশন গঠন।
- `banglanltk` অথবা `bnlp_toolkit` ব্যবহার করে বাংলা এনএলপি পাইপলাইন স্থাপন।
- `psutil` সঠিকভাবে ইন্সটল করে সিস্টেম রিসোর্স মনিটরিং সক্রিয় করা।
- এজেন্টকে বাংলায় যেকোনো প্রশ্নের উত্তর দেওয়ার সক্ষমতা, সত্যতা যাচাই, এবং মাল্টি-ল্যাঙ্গুয়েজ কোড সহায়তায় পারদর্শী করা।
- Editor ইন্টিগ্রেশন উপযোগী মিড-লেয়ার অর্কেস্ট্রেশন তৈরি।

## নির্ভরশীলতা ও সেটআপ ধাপ
1. Python ভার্চুয়াল এনভায়রনমেন্ট সক্রিয় (`.venv` অথবা `zombiecoder_env`)।
2. প্যাকেজ ইন্সটল:
   - `banglanltk` অথবা `bnlp_toolkit` (প্রাধান্য: উপলব্ধতার উপর নির্ভর)।
   - `psutil`
   - `langchain`, `langchain-community`, `langchain-core`
   - প্রয়োজনভেদে `sentencepiece`, `transformers`, `torch` (বাংলা মডেল সাপোর্টের জন্য)।
3. বিদ্যমান `unified_agent_system.py` বা সংশ্লিষ্ট মডিউল থেকে Ollama API কল ও কনফিগ অপসারণ।
4. নতুন কনফিগ ফাইল/সেটে বিমূর্ত অর্কেস্ট্রেশন লেয়ার যুক্ত করা (ইনপুট → প্রসেসর → রেসপন্স জেনারেটর → ভেরিফায়ার)।

## আর্কিটেকচার আপডেট পরিকল্পনা
- **ইনপুট গ্রহণ:** Flask API থেকে ইউজার মেসেজ সংগ্রহ, সেশন মেটাডেটা সংরক্ষণ।
- **মিড-লেয়ার অর্কেস্ট্রেশন:**
  - ক্যানোনিকাল প্রসেসর ক্লাস তৈরি যা LangChain `LLMChain`/`ConversationChain` ব্যবহার করবে।
  - বাংলা এনএলপি টোকেনাইজার (banglanltk/bnlp) দিয়ে প্রি/পোস্ট প্রসেসিং।
  - প্রয়োজন হলে ফ্যালব্যাক ইংরেজি মডেলের সাথে রাউটিং লজিক।
- **LLM প্রোভাইডার:** স্থানীয়/কাস্টম মডেল (উদাহরণ: Hugging Face Transformers) লোড করে LangChain-সামঞ্জস্যপূর্ণ `LLM` র‍্যাপার তৈরি।
- **ট্রাস্ট যাচাইকরণ:** বর্তমান যাচাইকরণ লজিক পুনর্লিখন করে বাংলা ভাষা ও সত্যতা নিশ্চিত করা।
- **সিস্টেম মনিটর:** psutil দিয়ে CPU/RAM রিপোর্টিং মডিউল আপডেট।

## বাস্তবায়নের ধাপ
1. ডিপেন্ডেন্সি ইন্সটলেশন কমান্ড প্রস্তুত ও টার্মিনাল লগ সংরক্ষণ।
2. কোডবেসে কনফিগ রিফ্যাক্টর: Ollama অংশ অপসারণ, LangChain ভিত্তিক মডিউল সংযোজন।
3. বাংলা এনএলপি পাইপলাইন ইন্টেগ্রেশন (স্টেমিং/টোকেনাইজিং/স্টপওয়ার্ড প্রয়োগ)।
4. এজেন্ট রেসপন্স কনটেক্সট: 
   - `ভাইয়া` প্রিফিক্স বাধ্যতামূলক।
   - সত্যতা যাচাইকরণ উন্নত করা (ভিন্ন ভাষা/ASCII আউটপুট নিষিদ্ধ)।
5. ইউনিট/ভ্যালিডেশন স্ক্রিপ্ট প্রস্তুত করে অন্তত ৩টি টেস্ট: 
   - বাংলা শুভেচ্ছা বার্তা।
   - কোড-সম্পর্কিত প্রশ্ন।
   - মিথ্যা তথ্যের অনুরোধে কিভাবে প্রতিক্রিয়া দেওয়া হবে।
6. টার্মিনাল লগ ও ফলাফল সংগ্রহ করে ডকুমেন্টেড প্রমাণ রাখা।
7. Git স্টেজিং ও কমিট (বিস্তারিত বার্তা সহ) প্রস্তুত করা।

## যাচাই ও প্রমাণ সংগ্রহ
- `python` বা Flask সার্ভার চালু করে `/v1/chat/completions` ও `/chat` এন্ডপয়েন্টে বাংলা কুয়েরি রান করে লগ সংগ্রহ।
- সিস্টেম রিসোর্স মনিটর রিপোর্ট (psutil) থেকে স্ক্রিন-লগ।
- বাংলা ইনপুটের ভিত্তিতে কাস্টম রেসপন্সের উদাহরণ সংরক্ষণ।
- ডিপেন্ডেন্সি ইন্সটল লগ (pip freeze স্ন্যাপশটসহ) সংযুক্ত করা।

## ঝুঁকি ও প্রতিকার
- বাংলা মডেল লোডিং সময় বেশি হতে পারে → লাইটওয়েট মডেল নির্বাচন ও ক্যাশিং।
- `banglanltk` ডাটা রিসোর্স ডাউনলোড লাগতে পারে → স্ক্রিপ্টে প্রথম রানেই হ্যান্ডল করা।
- psutil ইন্সটলে বিল্ড টুল প্রয়োজন হলে নির্দেশানুসারে ইনস্টলার লিংক/গাইড সংযোজন।

## পরবর্তী পদক্ষেপের ক্রম
1. ডিপেন্ডেন্সি ইন্সটল লগ সংগ্রহ।
2. কনফিগ ও কোড পরিবর্তন বাস্তবায়ন।
3. LangChain প্রসেসর ও বাংলা NLP পাইপলাইন পরীক্ষা।
4. এন্ড-টু-এন্ড চ্যাট ফ্লো ভেরিফাই করে লগ সংরক্ষণ।
5. Git কমিট প্রস্তুত ও সারাংশ তৈরি।
