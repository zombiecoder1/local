🚨 TROUBLESHOOTING QUICK REFERENCE
══════════════════════════════════════════════════════════════════

PROBLEM 1: Agent won't start
─────────────────────────────────────────────────────────────────
ERROR: python unified_agent_system.py fails

SOLUTION:
$ pip install -r requirements.txt
$ python unified_agent_system.py

Then check: http://localhost:8001/health


PROBLEM 2: Proxy won't start
─────────────────────────────────────────────────────────────────
ERROR: Port 5010 already in use

SOLUTION:
$ netstat -ano | findstr :5010
$ taskkill /PID [PID] /F
$ python proxy_simple.py

Then check: http://localhost:5010/health


PROBLEM 3: Cursor still uses cloud
─────────────────────────────────────────────────────────────────
REASON: Config not updated or Cursor cached old config

SOLUTION:
$ python Force_Cursor_Connector_ADAPTED.py
$ Close Cursor completely (end task)
$ Restart Cursor

Check: Settings → Model should show "ZombieCoder Local AI"


PROBLEM 4: "requests" module not found
─────────────────────────────────────────────────────────────────
ERROR: ImportError: No module named 'requests'

SOLUTION:
$ pip install requests

Then retry: python Force_Cursor_Connector_ADAPTED.py
